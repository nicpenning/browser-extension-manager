Help & Information

Risk Levels

High Risk

Extensions with permissions that can access sensitive data like cookies, history, passwords, or all websites.

Medium Risk

Extensions with permissions for tabs, storage, notifications, or specific website access.

Low Risk

Extensions with minimal permissions that pose little security risk.

No Risk

Extensions with no special permissions requested.

Permission Colors

High

Permissions that can access sensitive user data or significantly modify browser behavior.

Medium

Permissions that can access some user data or modify content on pages.

Low

Permissions with minimal security implications.

Features

Search: Filter extensions by name or description.

Filter: Show all, enabled, or disabled extensions.

Sort: Order by name, status, type, or risk level.

Permissions Filter: Find extensions with specific permissions.

Profiles: Save and restore extension configurations.

Click "+X more": Expand to see all permissions.
